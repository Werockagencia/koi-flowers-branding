# KOI Flowers · Propuestas de identidad — Ronda 01

Presentación web de las tres propuestas de logotipo para **KOI Flowers**, preparada por **We Rock Agencia**.

- `index.html` — portada, comparativa y formulario de comentarios
- `propuesta-01-kin.html` — Kin 金 · Oro Imperial
- `propuesta-02-mizu.html` — Mizu 水 · Flujo Neón
- `propuesta-03-yuhi.html` — Yūhi 夕日 · Atardecer

Cada universo incluye concepto, versiones del logo, construcción y área de protección, color, tipografía, elementos gráficos, usos incorrectos y mockups.

## Desarrollo
- `node src/build-logos.js` regenera `assets/logos.js` (sprite vectorial) desde las exportaciones SVG del PDF de Illustrator.
- `node src/serve.js` sirve el sitio en http://localhost:8765
